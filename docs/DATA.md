# Данные и воспроизводимость

CSV — реестр изображений, а не замена картинок и не средство сжатия. Из него автоматически строятся пути, Unicode-ключи и проверки полноты.

`data/source-catalog.csv` содержит все 3 988 исходных PNG: emoji, name, category, rgi, file, url, width, height, bytes, sha256. CSV сохранён с UTF-8 BOM для Excel. `file` — путь в первоначальном архиве; он не равен новому пути в npm-пакете.

`data/site-metadata.json` сохраняет subgroup, CLDR name и Unicode order. `data/emoji-data.upstream.json` — снимок iamcal/emoji-data, используется только при сборке для shortcodes и группировки вариантов. Его лицензия MIT сохранена. Изображения Apple/Facebook/Twitter и их координаты не копируются.

`emoji.json` — одна запись на реальный файл (3 988), включая все варианты кожи, семьи и флаги. `image` обозначает PNG basename; WebP использует тот же basename с другим расширением. `rgi` сохраняет оригинальный ключ Google с `_`; `unified` использует верхний регистр с `-`; имена изображений — unified в нижнем регистре. FE0F не выбрасывается из канонических имён, но API принимает предусмотренные алиасы без FE0F.

`emoji-datasource.json` — базовые записи и вложенные skin_variations. Записи, не найденные в снимке iamcal, добавляются отдельно. Проверка flatten-каталога гарантирует покрытие всех 3 988 кодов. Не утверждается полная совместимость со всеми потребителями emoji-data: намеренно отсутствуют legacy vendor codes, Apple-флаги и sprite-координаты. Два разных Unicode-кода могут иметь идентичное изображение — это не основание удалять запись.

`data/assets-lock.json` фиксирует sharp/libvips, параметры обработки, размер и SHA-256 каждого выходного файла. `manifest.json` — публичный индекс этих файлов. При регенерации на другой ОС/версии бинарного sharp результат может отличаться побайтово, даже если визуально эквивалентен. Готовый релиз фиксируется контрольными суммами; не пересоздавайте бинарные ресурсы существующей опубликованной версии.

Набор зафиксирован на 21.09.2026, не обещает включать будущие Unicode-обновления. Обновление снимка — отдельная версия с проверкой полного набора. API не запрашивает каталог сайта при каждом открытии приложения.
