# Проверка Noto 3D 1.0.0

Дата подготовки: 23.09.2026. Снимок исходных изображений: 21.09.2026.

## Комплект

- 3 988 уникальных записей из исходного CSV.
- 3 988 PNG 64 × 64; суммарно 26 763 670 байт.
- 3 988 WebP 128 × 128; суммарно 20 922 770 байт.
- 3 988 WebP 256 × 256; суммарно 45 240 234 байта.
- Всего изображений: 11 964; 92,926,674 байт.
- npm tarball: 94,497,982 байт; содержимое без сжатия: 102,350,152 байт.
- Файлов внутри npm tarball: 11,984.
- Runtime-зависимостей: 0.

## Выполненные проверки

- Node.js 24.19.0, npm 11.9.0, TypeScript 5.9.3, sharp 0.35.4.
- `npm run check`: сборка каталогов и модулей, 6 тестов, проверка типов, сверка состава и SHA-256 всех 11 964 файлов.
- API проверен для каждого из 3 988 Unicode-символов и канонических кодов; ESM и CommonJS дают одинаковые пути.
- Проверены составные эмодзи, семья с ZWJ, оттенок кожи, флаг, клавиша, варианты FE0F и явный текстовый FE0E.
- Все 11 964 изображения полностью декодированы; ширина и высота сверены с заявленным размером.
- `npm pack` создал tarball. В нём нет node_modules, исходников 512 px, кэша и вложенных архивов.
- Tarball установлен отдельным потребителем через `npm install --offline`; проверены ESM/CommonJS imports, декларации для `.mts`/`.cts`, JSON exports и доступ к PNG/WebP из установленного пакета.
- После этой установки изменён только текст инструкции по Git; финальный tarball пересобран, содержимое повторно проверено.

## Что требует действий владельца

Пакет не опубликован в npm; файлы не отправлены в GitHub. Публичные CDN URL проверяются после публикации владельцем. Учётная запись npm, доступность имени и OIDC-настройки относятся к его аккаунту. Автоматическая публикация запускается только вручную по тегу.

В LICENSE.md зафиксировано противоречие между README и корневой лицензией Google; применимость условий к статическим 3D PNG требует уточнения перед публичным распространением. Код проекта и метаданные iamcal лицензируются отдельно от графики.

Проверки выполнены на Linux. Для Windows и macOS приведены переносимые команды Node.js; отдельный запуск на этих ОС не выполнялся. Локальная HTML-галерея включена как пример; визуальная проверка в браузере не выполнялась.
